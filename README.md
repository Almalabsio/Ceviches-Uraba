# Ceviches Urabá - Sitio Web Oficial

Este proyecto es el sitio web oficial de **Ceviches Urabá**, un restaurante familiar ubicado en Turbo Ciudad Puerto, Antioquia. El sitio destaca por su enfoque en la frescura radical y la integración vertical (cultivo propio de camarón).

## Características principales:
- **Diseño Premium:** Estética costera y elegante con animaciones suaves (AOS).
- **Asistente IA (Valentina):** Chatbot inteligente con comportamiento auténtico costeño integrado vía Airforce API.
- **Optimizado para Móviles:** Totalmente responsivo para una experiencia impecable en cualquier dispositivo.
- **Multimedia:** Incluye videos cinematográficos de los productos y del proceso de cultivo.

## Estructura de archivos:
- `index.html`: Estructura principal del sitio.
- `style.css`: Estilos personalizados y diseño de chat tipo WhatsApp.
- `script.js`: Lógica de interactividad y conexión con la IA.
- `promptvalentina.txt`: Documento fuente de la personalidad y reglas de la IA.

## Configuración del Chatbot:
Para activar la IA, abre `script.js` y coloca tu **API Key de Airforce** en la constante `API_KEY` dentro de la función `getAIResponse`.

## Despliegue en GitHub Pages:
1. Crea un repositorio en GitHub.
2. Sube todos los archivos (incluyendo imágenes y videos).
3. Ve a `Settings` > `Pages`.
4. Selecciona la rama `main` y guarda.
5. ¡Listo! Tu página estará en línea en minutos.
